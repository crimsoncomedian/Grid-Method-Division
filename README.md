# Grid Method: Division

An interactive for the grid method of long division with 3- and 4-digit dividends and divisors from 5 to 50. Each digit of the dividend gets its own column. In each column the student writes how many times the divisor fits, multiplies, subtracts, and then brings the remainder up into the front of the next column, ready to continue.

Open `index.html` in a browser, no build step needed.
